1. What You Need

Welcome! Telegram Drive lets you store unlimited files for free using your Telegram account as cloud storage.

Before you begin, make sure you have:

  • A Telegram account (download the app from telegram.org if you don't have one)
  • Your phone number registered with Telegram
  • A web browser (you're already here! ✔)

2. Get API Credentials

You need an API ID and API Hash from Telegram. These are free and take 2 minutes:

  1. Open my.telegram.org in your browser
  2. Enter your phone number (with country code, e.g. +91...)
  3. Enter the verification code sent to your Telegram app
  4. Click "API development tools"
  5. Fill in any App title and Short name (e.g. "MyDrive")
  6. Click "Create application"
  7. Copy your API ID (a number) and API Hash (a long code)

Keep these safe. You will paste them on the login form.

3. Choose Login Method

On the login form, you will see two tabs at the top. Pick the one that suits you:

User Phone

Best for personal use. Files are saved in your "Saved Messages". Simple and quick.

Bot Token

Best for shared or advanced use. Files are saved in a Telegram Channel. Requires extra setup (Steps 5 and 6).

4. Login with Phone

If you chose "User Phone", follow these steps:

  1. Paste your API ID and API Hash into the form
  2. Enter your phone number (with country code, e.g. +911234567890)
  3. Click "Send Code"
  4. Open Telegram on your phone. You will receive a 5-digit code
  5. Enter the code and click "Verify"
  6. If you have 2FA enabled, you will be asked for your password too

That's it! You're logged in. Skip to Step 7.

5. Create a Bot (Bot Login Only)

If you chose "Bot Token", you first need to create a bot:

  1. Open Telegram and search for @BotFather
  2. Send the command /newbot
  3. Give your bot a name (e.g. "My Drive Bot")
  4. Give it a username ending in "bot" (e.g. "mydrive_bot")
  5. BotFather will reply with a Bot Token that looks like: 123456:ABCdef...
  6. Copy the token. You will paste it on the login form

6. Setup Storage Channel (Bot Only)

Your bot needs a channel to store files in:

  1. In Telegram, tap "New Channel"
  2. Give it any name (e.g. "My Drive Storage")
  3. Make it Private (recommended)
  4. Go to Channel Settings, then Administrators, then Add Admin
  5. Search for your bot by its username and add it as Admin
  6. Grant permissions: Post, Edit, and Delete Messages
  7. Get the Channel ID: forward any message from the channel to @userinfobot. It will reply with the ID (starts with -100...)

Paste the Bot Token and Channel ID into the login form, then click "Login as Bot".

7. Start Using Your Drive!

You're all set! Here's what you can do:

  • Upload — Click "New Upload" or drag and drop files
  • Organize — Create folders to keep files tidy
  • Preview — Double-click files to preview them
  • Download — Click the download icon on any file
  • Star — Mark important files for quick access
  • Trash — Right-click any file for more options

Your storage is unlimited and completely free!
